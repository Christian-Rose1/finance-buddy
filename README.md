# Finance Buddy Starter

This is the first working scaffold for the Finance Buddy MVP.

## What is included
- Next.js App Router structure
- Tailwind starter styling
- Landing page
- Dashboard shell
- Upload page
- Supabase client helper
- Placeholder upload API route

## What to do next
1. Run `npm install`
2. Create a Supabase project
3. Fill in `.env.local` from `.env.example`
4. Add Google auth in Supabase
5. Connect the upload form to storage and a database table

## Pages
- `/` marketing landing page
- `/dashboard` app dashboard shell
- `/upload` statement upload shell

## Notes
This starter intentionally keeps the MVP narrow: statement upload, dashboard, and the plumbing for analysis later.
